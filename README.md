# Olá, eu sou o Igor Bibiano 👋

Estudante de **Análise e Desenvolvimento de Sistemas** focado em desenvolvimento **back-end com Java**. Gosto de construir APIs REST bem estruturadas, com regras de negócio claras, validação de dados e persistência em banco relacional.

- 🤖 Uso **engenharia de prompt** e ferramentas de IA para acelerar estudos e desenvolvimento.
- 💼 Em busca de uma oportunidade de **estágio** para aplicar meus conhecimentos em desafios reais.
